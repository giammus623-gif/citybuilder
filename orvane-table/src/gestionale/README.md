# Gestionale (pacchetto Premium): volutamente vuoto

Il gestionale comande, tavoli e stampa in cucina **non si costruisce adesso**:

- Parte 6.1: la fase 4 parte solo se almeno due clienti hanno chiesto il Premium o hanno accettato di firmarlo con acconto.
- Parte 0.2, regola 4: nessuna funzione senza un cliente pagante che l'abbia chiesta.
- Parte 5.6bis: prima di promettere il Premium serve un collaudo di un'ora con le stampanti del cliente.

Quando succederà: il gestionale esistente del fondatore resta un modulo separato (Parte 5), si adatta a più locali usando lo stesso `locale_id` e le stesse regole di accesso dello schema in `supabase/migrations/`, e la stampa si progetta con il prompt 17.13 (`prompt/LIBRERIA.md`). Il documento stampato al tavolo porta sempre la dicitura «documento non fiscale».
